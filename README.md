# 💌 Borang Maklum Balas — Misi Penjelajah Koordinat

Website borang maklum balas bertema cute pastel/retro untuk aktiviti **Misi Penjelajah Koordinat**.

## 📁 Fail

- `index.html` — fail utama website
- `README.md` — panduan penggunaan dan deployment

## 🚀 Cara deploy ke GitHub Pages

1. Buka GitHub dan buat repository baharu.
2. Namakan repository, contohnya:
   `misi-koordinat-feedback`
3. Upload:
   - `index.html`
   - `README.md`
4. Pergi ke **Settings → Pages**.
5. Di bahagian **Build and deployment**, pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Klik **Save**.
7. GitHub akan beri link website selepas deployment selesai.

## 💌 Fungsi borang

Website mempunyai:

- Nama / nama samaran
- Jenis maklum balas:
  - 💬 Komen
  - 💭 Pandangan
  - 💡 Cadangan
- Rating 1–5 bintang
- Ruang menulis maklum balas
- Paparan **Kata Rakan-Rakan**
- Kad feedback dengan gaya pastel/cute
- Popup selepas feedback dihantar
- Responsive untuk telefon, tablet dan komputer

## 🗄️ Simpan feedback untuk semua pengguna

GitHub Pages ialah hosting statik, jadi ia tidak menyediakan database untuk menyimpan jawapan borang.

Website ini boleh disambungkan kepada **Supabase** supaya:

> Pelajar A hantar feedback → feedback disimpan dalam database → Pelajar B boleh nampak feedback tersebut.

### 1. Buat project Supabase

Buat satu project baharu di Supabase.

Kemudian buka:

**SQL Editor → New Query**

Masukkan SQL berikut:

```sql
create table public.feedback (
  id bigint generated by default as identity primary key,
  name text not null,
  type text not null default 'Komen',
  rating integer not null default 1
    check (rating between 1 and 5),
  message text not null,
  created_at timestamptz not null default now()
);

alter table public.feedback enable row level security;

create policy "Anyone can read feedback"
on public.feedback
for select
to anon
using (true);

create policy "Anyone can submit feedback"
on public.feedback
for insert
to anon
with check (
  char_length(name) between 1 and 40
  and char_length(message) between 1 and 500
  and rating between 1 and 5
  and type in ('Komen', 'Pandangan', 'Cadangan')
);
```

### 2. Ambil URL dan key Supabase

Dalam Supabase pergi ke:

**Project Settings → API**

Ambil:

- Project URL
- Publishable/anon key

### 3. Masukkan dalam `index.html`

Cari bahagian:

```js
const SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL_HERE";
const SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE";
```

Gantikan dengan URL dan anon/publishable key project anda.

Contoh:

```js
const SUPABASE_URL = "https://xxxxx.supabase.co";
const SUPABASE_ANON_KEY = "xxxxx";
```

**Jangan masukkan `service_role` atau secret key ke dalam `index.html`.**

## 🌷 Mod demo

Kalau Supabase belum disambungkan, website masih boleh digunakan sebagai demo.

Feedback akan disimpan menggunakan `localStorage` pada browser tersebut.

Tetapi dalam mod demo:

- feedback hanya nampak pada browser/peranti yang sama
- pengguna lain tidak akan nampak feedback tersebut

Untuk penggunaan sebenar bersama pelajar, sambungkan Supabase.

## ✨ Popup feedback

Selepas seseorang berjaya menghantar feedback, website akan menunjukkan popup:

**“💌 Maklum balas baharu!”**

Untuk popup automatik secara live apabila *orang lain* menghantar feedback ketika pengguna sedang membuka website, Supabase Realtime boleh ditambah pada versi seterusnya.
