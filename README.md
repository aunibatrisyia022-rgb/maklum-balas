# 💌 Cute Feedback Site — GitHub Pages + Supabase

Site ini ialah borang maklum balas cute untuk **Misi Penjelajah Koordinat**.

## 1. Deploy ke GitHub

1. Create repository baru, contoh `misi-koordinat-feedback`.
2. Upload `index.html`.
3. Pergi **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Pilih `main` dan folder `/root`.
6. Save.

## 2. Supaya maklum balas boleh dilihat oleh semua orang

GitHub Pages sendiri ialah hosting statik, jadi ia tidak menyimpan data borang. Site ini disediakan dengan sambungan **Supabase**.

Create satu project di Supabase, kemudian buka **SQL Editor** dan jalankan:

```sql
create table public.feedback (
  id bigint generated by default as identity primary key,
  name text not null,
  type text not null default 'Komen',
  rating integer not null default 1 check (rating between 1 and 5),
  message text not null,
  created_at timestamptz not null default now()
);

alter table public.feedback enable row level security;

create policy "Anyone can read feedback"
on public.feedback
for select
to anon
using (true);

create policy "Anyone can submit feedback"
on public.feedback
for insert
to anon
with check (
  char_length(name) between 1 and 40
  and char_length(message) between 1 and 500
  and rating between 1 and 5
  and type in ('Komen','Pandangan','Cadangan')
);
```

Kemudian:

**Supabase → Project Settings → API**

Copy:
- Project URL
- Publishable/anon key

Dalam `index.html`, cari:

```js
const SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL_HERE";
const SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE";
```

gantikan dengan nilai Supabase anda.

### Penting
Jangan letak `service_role` / secret key dalam `index.html`. Untuk GitHub Pages gunakan **anon/publishable key sahaja** dengan RLS seperti SQL di atas.

## 3. Fungsi yang sudah ada

- Cute retro/pastel interface inspired by the supplied reference.
- Feedback form.
- Komen / Pandangan / Cadangan.
- Rating 1–5 bintang.
- Public feedback wall.
- Feedback cards with different cute paper colours.
- Popup selepas feedback berjaya dihantar.
- Auto-load feedback terbaru.
- Responsive phone/tablet/desktop.
- Demo mode menggunakan localStorage jika Supabase belum disambungkan.

## 4. Kalau nak popup maklum balas secara live

Versi ini refresh feedback apabila page dibuka dan selepas submission. Untuk **popup automatik apabila orang lain menghantar feedback ketika pengguna sedang membuka website**, Supabase Realtime boleh ditambah kemudian.
